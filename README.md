# 听见另一种画面｜可部署网站

一个可多人使用的声音分享与声音盲盒网站。采用 Node.js + Express + SQLite，音频保存在服务器持久化目录。

## 已实现功能

- 用户注册、登录、退出；昵称唯一，密码使用 bcrypt 哈希保存。
- 匿名展示分享者昵称（注册昵称），上传声音需审核后公开。
- 音频上传（MP3/WAV/OGG/M4A/AAC/WEBM，最大 20MB）。
- 声音盲盒：播放、选择选项、猜错继续、揭晓答案。
- 积分：第一次答对 3 分、第二次 2 分、第三次及以后 1 分；猜错不扣分；主动揭晓 0 分。每个用户每条声音只可成功结算一次。
- 留言互动、个人空间、积分榜。
- 管理员审核台：通过或退回待审核声音。
- SQLite 数据库、登录会话、基础安全响应头和 API 限流。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
```

复制 `.env.example` 为 `.env`，至少修改 `SESSION_SECRET` 和 `ADMIN_PASSWORD`。然后设置环境变量并运行：

```bash
npm start
```

浏览器打开 http://localhost:3000 。管理员使用 `ADMIN_NICKNAME` / `ADMIN_PASSWORD` 登录，普通用户自行注册。

## 发布到 Render

1. 将整个项目上传到 GitHub 仓库。
2. 在 Render 选择 New → Blueprint，连接仓库并读取 `render.yaml`。
3. 首次部署时，按提示填写 `ADMIN_PASSWORD`。请使用强密码，不要把密码提交到 GitHub。
4. 等待部署完成，Render 会提供一个 `onrender.com` 公网网址。
5. 数据库和上传音频保存在 `/var/data` 持久化磁盘中。

Render 持久化磁盘通常需要付费套餐。请在确认价格后再创建付费资源。

## 上线前建议

- 把默认管理员昵称 `admin` 改成不容易猜到的昵称，并设置强密码。
- 增加隐私政策、用户协议、举报与内容删除机制。
- 当前审核需人工核验音频分享权利。
- 正式公开运营前建议增加邮箱验证、密码找回和更完善的反滥用机制。

## 数据备份

备份 `DATA_DIR` 目录中的 SQLite 数据库及 `UPLOAD_DIR` 中的音频文件。建议定期备份。
